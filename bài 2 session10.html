Phần 1. Báo cáo phân tích input và output

  • Input (Văn bản thô): Các đoạn text thuần túy mô tả quy trình, mã lệnh, danh sách vật tư và các ghi chú kỹ thuật cài đặt cảm biến độ ẩm cho trang trại Lan chưa qua định dạng Markdown.

  • Output (Giao diện render chuyên nghiệp): Tài liệu hướng dẫn trực quan, có cấu trúc rõ ràng với:

  • Inline Code : cho các tên biến, từ khóa và câu lệnh ngắn.

  • Code Block : (có Syntax Highlighting cho Python) để hiển thị đoạn mã điều khiển máy bơm.

  • Bảng so sánh : trực quan giữa cảm biến độ ẩm đất loại cũ và loại mới.

  • Task List : giúp kỹ thuật viên dễ dàng tick chọn các bước kiểm tra thiết bị.

  • Ký tự Escape ( / ) : được sử dụng chính xác để hiển thị các ký tự đặc biệt (như # hoặc * ) mà không bị lỗi cú pháp Markdown.

Phần 2 . Source code

Hướng dẫn cài đặt cảm biến độ ẩm (Vườn Lan)

Lưu ý quan trọng

  • Tuyệt đối không chạm tay trực tiếp vào mạch điện khi chưa ngắt nguồn
  • Tránh để nước tiếp xúc trực tiếp với bo mạch trung tâm

1. Task List kiểm tra thiết bị

  • Kiểm tra nguồn điện ổn định 5V/12V.
  • Cài đặt thư viện bằng lệnh pip install RPi.GPIO. -
  • Kết nối biến pin_sensor = 4 với cảm biến.
